## 2. 产品背景与目标

### 2.1 背景

传统招聘流程存在以下痛点：
- HR 简历筛选成本高、效率低
- JD 与简历匹配高度依赖人工经验
- 初筛与面试沟通重复、标准不统一
- 技术岗位筛选对 HR 专业能力要求高

随着大模型与 LangChain Agent 能力成熟，可以将招聘流程中的 **信息理解、匹配、问答、评估** 自动化、智能化。

### 2.2 产品目标

构建一套 **以 LangChain 为核心的智能招聘系统**，实现：
- AI 自动解析 JD 与简历
- AI 候选人匹配与评分
- AI 面试官（初筛/技术/行为面）
- 招聘知识库 + 可解释推荐

目标用户：
- 企业 HR
- 用人部门（技术负责人）
- 中小企业招聘负责人

## 3. 用户画像

### 3.1 HR 用户
- 非技术背景
- 关注：效率、合规性、候选人质量
- 痛点：筛简历慢、沟通成本高

### 3.2 技术负责人
- 技术背景
- 关注：候选人真实能力
- 痛点：简历注水、面试质量不稳定

### 3.3 候选人
- 关注：反馈速度、公平性、体验

## 4. 产品整体架构

### 4.1 架构总览

```
前端（Web / H5）
        ↓
后端业务服务（招聘流程 / 权限 / 数据）
        ↓
AI 调度层（LangChain）
  - Prompt 管理
  - Chain / Agent
  - Tool 调用
        ↓
大模型（GPT / Claude / 本地模型）
        ↓
向量数据库（简历 / JD / 面试知识库）
```

### 4.2 LangChain 角色

- LLMChain：JD 解析、简历解析
- RetrievalQA：招聘知识库问答
- Agent：
  - 简历评估 Agent
  - 面试官 Agent
  - 招聘助理 Agent

## 5. 功能模块拆解

## 5.1 JD 管理模块

### 功能点
- JD 创建 / 编辑
- JD AI 优化建议
- JD 结构化解析

### AI 能力
- 提取：技能栈 / 年限 / 学历 / 项目经验
- 输出结构化 JD JSON

---

## 5.2 简历解析模块

### 功能点
- 简历上传（PDF / Word）
- 自动解析
- 候选人画像生成

### AI 能力
- 简历语义解析
- 技能标签抽取
- 项目真实性评估（规则 + LLM）

---

## 5.3 人岗匹配与评分模块（核心）

### 功能点
- JD ↔ 简历匹配
- 候选人推荐列表
- 匹配原因解释

### 匹配维度
- 技能匹配度（权重最高）
- 项目经验
- 行业背景
- 稳定性（频繁跳槽）

### AI 实现
- 向量相似度（Embedding）
- LLM 语义打分
- 规则 + AI 混合评分

---

## 5.4 AI 面试官模块

### 面试类型
- 初筛面试（HR）
- 技术面试
- 行为面试

### 功能点
- 自动生成面试问题
- 多轮追问
- 面试记录总结
- 面试评分与结论

### AI 设计
- Agent + Memory
- 不同角色 Prompt 模板
- 可配置问题难度

---

## 5.5 招聘知识库（RAG）

### 内容来源
- 公司岗位标准
- 面试题库
- 历史优秀候选人

### 能力
- HR 招聘问答
- 面试官辅助决策

---

## 5.6 招聘流程管理

- 候选人状态流转
- AI 建议是否进入下一轮
- 人工确认兜底

## 7. 非功能需求

### 7.1 性能
- 单次 AI 请求 < 10s
- 支持并发面试

### 7.2 安全与合规
- 简历数据加密
- 模型脱敏处理
- 操作日志审计

### 7.3 可解释性
- 所有 AI 结论必须可解释
- 显示评分依据
