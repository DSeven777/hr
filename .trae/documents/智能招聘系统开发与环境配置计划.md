# 智能招聘系统开发计划与技术选型

基于 PRD 文档与项目工程规范，制定以下开发计划。

## 1. 技术选型与环境版本 (Tech Stack)

针对 LangChain 开发环境，建议采用以下稳定且主流的组合：

### 核心环境
- **Python**: `3.11.x` (兼顾性能与库兼容性，符合 >=3.10 要求)
- **LangChain**: `v0.3.x` (最新稳定体系)
  - `langchain`
  - `langchain-community`
  - `langchain-core`
  - `langchain-openai` (标准 LLM 接入)
  - `langchain-text-splitters`

### 基础设施 (Infra)
- **Vector DB**: `FAISS` (开发阶段推荐，轻量无需 Docker) 或 `Chroma`。生产环境可迁移至 `Milvus`。
- **Web Framework**: `FastAPI` (用于对外暴露 Agent 接口)
- **Validation**: `Pydantic v2` (LangChain 新版标配)
- **Env Management**: `python-dotenv`

### 依赖文件示例 (requirements.txt)

## 2. 工程架构设计 (Architecture)

严格遵循 `.trae/rules/python.md` 的五层架构：

- **src/domain**: 定义 `Resume`, `JobDescription`, `MatchResult` 等 Pydantic 模型。
- **src/prompt**: 管理 Jinja2 模板 (JD 解析, 简历提取, 匹配打分)。
- **src/infra**: 封装 LLM (OpenAI/Local) 和 VectorStore (FAISS) 的实现，实现依赖倒置。
- **src/chain**: 实现单一职责的 Chain (`ResumeParseChain`, `JDAnalysisChain`, `MatchingChain`)。
- **src/service**: 业务逻辑层，组合 Chain 完成 "上传简历->解析->匹配" 的完整流程。

## 3. 开发里程碑 (Milestones)

### Phase 1: 基础建设 (Infrastructure)
1.  **项目初始化**: 创建符合规范的目录结构 (`src/{domain,infra,chain,service,prompt}`)。
2.  **环境配置**: 编写 `pyproject.toml` / `requirements.txt` 及 `.env` 模板。
3.  **Infra 实现**: 封装 `LLMProvider` 和 `VectorStoreWrapper` 基础类。

### Phase 2: 核心业务 V1.0 (Core Features)
1.  **JD 管理模块**:
    - 定义 `JobDescription` 领域模型。
    - 实现 JD 关键信息提取 Prompt 与 Chain。
2.  **简历解析模块**:
    - 集成 PDF/Word 读取工具 (`PyPDFLoader` 等)。
    - 实现 `ResumeParseChain`，输出结构化 JSON。
3.  **人岗匹配模块 (RAG)**:
    - 实现简历与 JD 的 Embedding 存储。
    - 实现 `MatchingChain`: 向量检索 + LLM 深度评估打分。

### Phase 3: API 服务化 (Service Layer)
1.  **Service 封装**: 创建 `RecruitmentService` 统一调度。
2.  **API 暴露**: 使用 FastAPI 提供 REST 接口供后端业务调用。
